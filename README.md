# Job Tracker

A simple and efficient Job Application Tracker built with **React**,
**TypeScript**, **Vite**, and **Tailwind CSS**.

## 🚀 Features

- Add, edit, and delete job applications
- View all applications in a sortable table
- Highlight old applications with no follow-up
- Modal form for clean and easy data entry
- Responsive UI with Tailwind CSS
- API integration for data persistence (RESTful endpoints)

## 🛠 Tech Stack

- **React** – UI framework
- **TypeScript** – Strong typing
- **Vite** – Lightning-fast development tooling
- **Tailwind CSS** – Utility-first CSS framework
- **Node.js/Express** (optional backend) – API layer for CRUD operations

## 📦 Installation

```bash
git clone https://github.com/DonkeyhTv/jobTracker.git
cd jobTracker
npm install
npm run dev
```
